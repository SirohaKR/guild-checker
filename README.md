# 우리 길드원 관리 (guild-checker)

## 개요

메이플스토리 길드 운영진이 쓰는 웹 도구예요. **이중길드**(같은 사람이 다른 길드에도 본캐·부캐를 두는 것)를 찾아내고, **가입 신청자**를 확인해요.

| 탭 | 하는 일 |
|---|---|
| **길드원 검색** | 우리 길드원 전원을 최신 정보로 갱신한 뒤 계정(유니온 대표 = 본캐)별로 묶어서, 본캐나 부캐가 다른 길드에 있는 사람을 찾아요. 의심 길드는 그 길드의 길드원 전부까지 확인해요(심층). 지난 기록과 비교도 돼요. |
| **캐릭터명 검색** | 가입 신청자의 **메이플 핸즈+ 캐릭터 목록 스크린샷**을 올리면 닉네임을 읽어(Claude 이미지 인식) → 사람이 검수 → 캐릭터마다 길드·본캐를 조회해요. |
| **길드 검색** | 아무 길드나 길드원 목록을 계정별로 봐요. 의심 결과의 [길드 검색] 버튼을 누르면 그 길드 + 찾을 계정이 채워져 바로 검색돼요. |
| **설정** | 넥슨·Claude API 키(받는 방법 안내 포함), 우리 길드(월드·이름), 이미지 읽기 모델. `data/guild.db`에 저장돼서 계속 유지돼요. 같이 쓰기면 내 비밀번호·계정 관리(관리자)도 여기서. |

### 사용 방식 (처음 들어올 때 한 번 고름)

| | 다른 사람과 같이 쓰기 | 저 혼자만 쓰기 |
|---|---|---|
| 로그인 | 모두 아이디·비밀번호로 로그인 (30일 유지) | 없음 |
| 계정 | 처음 고른 사람이 **관리자** 계정을 만들고, 관리자가 '설정'에서 운영진 계정을 미리 추가 (회원가입 없음) | — |
| API 키·우리 길드·검색 기록 | **계정마다 따로** | 하나 |
| `.env` 키 | 안 씀 (남의 키를 빌려 쓰지 않게) | 설정이 비었으면 씀 |

- 혼자 쓰다가 '설정 → 다른 사람과 같이 쓰기로 바꾸기'로 바꿀 수 있어요. 지금 설정·기록은 새 관리자 계정으로 옮겨져요.
- 비밀번호는 해시로만 저장해요. 잊으면 관리자가 '비밀번호 초기화'를 해 줘요.
- **처음 접속한 사람이 방식을 정하고 관리자가 돼요.** 주소를 남에게 알리기 전에 먼저 들어가서 정해 두세요.

### 의심을 가리는 방법

1. **검색 전에 정보 갱신** — 캐릭터·길드 정보는 날짜 없이(최신으로) 다시 받아요. 넥슨 정보는 그 캐릭터로 접속해야 갱신돼요.
2. **계정 묶기** — 유니온 랭킹(`/ranking/union`)에 아무 캐릭터나 넣으면 그 계정의 유니온 대표(보통 본캐)가 나와요. 대표가 같으면 같은 계정이에요(같은 월드).
3. **다른 길드 대조** — 캐릭터 정보에 다른 길드로 나오면, **그 길드의 길드원 목록**을 받아 실제로 있는지 확인해요.
   - **포착**: 그 길드 목록에도 있음 → 확실히 다른 길드
   - **정보 갱신 필요**: 그 길드 목록엔 없음 → 캐릭터 정보가 옛날 것. 신청자에게 **그 캐릭터로 한 번 접속해 달라고** 요청
   - **확인 불가**: 최신 정보나 길드 목록을 못 받음 → [메애기](https://meaegi.com/) 링크로 직접 확인
4. **심층·역방향** — 의심 길드의 길드원 전부, (선택) 길드 랭킹 상위 N개 길드의 길드원까지 대표를 확인해서 숨은 부캐를 찾아요.
5. **잘못 읽은 닉네임 바로잡기** — 이미지 인식은 '뇬·쀼' 같은 드문 글자를 '논·뿌'로 읽기 쉬워요. 없는 이름이 나오면 헷갈리는 자모(ㅗ/ㅛ, ㅜ/ㅠ, ㅂ/ㅃ, 받침 ㅅ/ㅆ …)를 바꿔 넥슨에서 찾고, **같은 계정** 캐릭터면 제안해요.

### 한계
- 유니온 대표 ≠ 본캐일 수 있어요(게임에서 바꿀 수 있음). 같은 계정 판별은 문제없어요.
- **월드 단위**예요(유니온이 월드별). 다른 월드 부캐는 연결 안 돼요.
- 유니온 랭킹은 **하루 전** 데이터라, 오늘 만든 캐릭터나 랭킹에 없는 계정은 '판별 불가'로 따로 보여줘요.
- 넥슨 API로는 한 계정의 캐릭터 목록 전체를 알 수 없어요 → 그래서 핸즈 스크린샷을 받아요.

## 예상 API 사용량 (검색 한 번에)

캐시: 이름→ocid **30일**, 유니온 대표 **3일**, 길드 이름→id **30일** 동안 다시 안 불러요.
캐릭터·길드 정보는 **매번 최신으로 다시** 받아요(검색 전 갱신). 그래서 첫 검색만 많고, 다시 할 땐 적어요.
가짜 넥슨 서버로 실제 호출 수를 세서 아래 공식과 맞는지 확인했어요(`tests/`).

### 길드원 검색
기호: M 우리 길드 캐릭터 수 · A 계정 수 · O 길드 밖에 있는 대표 수 · G 의심 길드 수 · S 의심 길드 길드원 합계 · N 역방향 길드 수 · T 그 길드원 합계

| 언제 | 호출 |
|---|---|
| 매번 | 길드 정보 `1 + G (+N)` · 캐릭터 최신 정보 `M + O (+찾은 부캐)` · 길드 랭킹 `⌈N/200⌉` |
| 그날 첫 검색 (30일 성장 켬) | + 30일 전 정보 `A` |
| 대표 캐시가 없을 때 (처음 / 3일마다) | + 유니온 대표 `M + S (+T)` |
| ocid 캐시가 없을 때 (처음 / 30일마다) | + 이름→ocid `M + O + S (+T)` · 길드 id `1 + G (+N)` |

예) 캐릭터 200 · 계정 70 · 길드 밖 대표 10 · 의심 길드 3개(길드원 600):

| | 역방향 끔 | 역방향 상위 50 (길드원 약 7,500) | 역방향 상위 200 (약 30,000) |
|---|---|---|---|
| 처음 | 약 **1,900** | 약 **17,000** | 약 **62,000** |
| 3일 안에 다시 (같은 날) | 약 **220** | 약 **270** | 약 **420** |
| 3일 안에 다시 (다음 날, 성장 확인) | 약 **290** | 약 **340** | 약 **490** |
| 3일 지나서 (대표 다시 확인) | 약 **1,100** | 약 **8,600** | 약 **31,000** |

### 캐릭터명 검색 (이름 K개)
| | 호출 |
|---|---|
| 처음 | 약 `3K` (ocid·최신 정보·대표) + 의심 길드마다 2 |
| 다시 (3일 안) | 약 `K + 1` + 의심 길드마다 1 |
| 잘못 읽은 이름 | 이름 하나당 + 최대 40 (보통 5~15, 비슷한 글자 후보를 찾아봄) |

예) 핸즈 캐릭터 35명: 처음 약 **106**, 다시 약 **36**. 닉네임 읽기(스크린샷)는 넥슨이 아니라 **Claude 1회**예요.

### 길드 검색 (그 길드 캐릭터 M')
| | 호출 |
|---|---|
| 처음 | 약 `2 + 3M'` + 길드 밖 대표마다 2 + 의심 길드마다 2 |
| 다시 (3일 안) | 약 `1 + M'` + 길드 밖 대표마다 1 + 의심 길드마다 1 |

예) 200명 길드: 처음 약 **620**, 다시 약 **215**.

넥슨 키의 하루·초당 한도는 [넥슨 Open API](https://openapi.nexon.com/ko/) 내 애플리케이션 화면에서 확인할 수 있어요(공개 문서엔 숫자가 없음).
한도를 넘으면 넥슨이 `429 OPENAPI00007`을 돌려주고, 이 앱은 잠깐 쉬었다가 다시 시도해요. 결과 화면 오른쪽 위에 실제 호출 수가 나와요.


## 환경 설정 (.env, 선택)

**보통은 필요 없어요** — 키와 우리 길드는 **설정 탭**에서 넣으면 `data/guild.db`에 저장돼요.
설정 탭이 비어 있을 때만 `.env` 값을 써요(서버에서 미리 정해 두고 싶을 때).

```bash
cp .env.example .env     # 그다음 .env를 열어 값을 채움
```

| 변수 | 뜻 |
|---|---|
| `NEXON_API_KEY` | 넥슨 Open API 키 (설정 탭 값이 우선) |
| `ANTHROPIC_API_KEY` | Claude API 키 (설정 탭 값이 우선) |
| `CLAUDE_MODEL` | 이미지 읽기 모델 기본값 (`claude-opus-5-5` / `claude-sonnet-5-5` / `claude-haiku-5-5`) |
| `WORKERS` | 넥슨 API 동시 호출 수 (기본 8) |
| `REP_TTL_DAYS` | 유니온 대표 결과를 며칠 동안 다시 쓸지 (기본 3) |
| `DB_PATH` | DB 파일 위치 (기본 `data/guild.db`) |

`.env`와 `data/`는 GitHub에 올라가지 않아요(`.gitignore`). **`data/guild.db`에는 API 키가 들어 있으니 남에게 주지 마세요.**
'혼자 쓰기'는 로그인이 없어서 주소를 아는 사람은 저장된 키로 검색할 수 있어요(키 자체는 앞뒤 몇 글자만 보여요). 밖에서도 열리게 할 거면 '같이 쓰기'를 쓰세요.

## 필요한 API 키

| 키 | 용도 | 받는 곳 |
|---|---|---|
| **넥슨 Open API 키** (필수) | 길드·캐릭터·유니온 랭킹 조회 | <https://openapi.nexon.com/ko/> → 로그인 → 애플리케이션 등록 → 메이플스토리 API 키 (개발용 `test_…` / 서비스용 `live_…`) |

haiku는 드문 글자를 자주 틀려서 opus를 권해요.

## 파일 설명

| 파일 | 역할 |
|---|---|
| `app.py` | Flask 서버. 사용 방식·로그인·계정 관리, 계정별 설정, 검색 시작·진행률·결과, 캐릭터명 조회, 이미지 읽기 API. |
| `checker.py` | **검색 핵심.** 최신 정보 갱신 → 대표로 묶기 → 다른 길드 대조(포착/갱신 필요) → 심층·역방향, 닉네임 바로잡기 제안. |

| `static/app.js` | 화면 로직(탭 이동, 진행률, 결과 카드, 의심 링크, 스크린샷 올리기·검수). |
| `static/style.css` | 단풍색 라이트 / 다크 테마(그라데이션 없음), 메이플스토리체, 폰 화면. |
| `static/logo.svg` | 사이트 아이콘·로고. |
| `tests/` | 가짜 넥슨 서버와 테스트(`test_checker.py` 검색, `test_app.py` 계정). |
| `Dockerfile`, `docker-compose.yml`, `.env.example` | 컨테이너(포트 `5080:5000`, `./data` 마운트)와 환경 변수 예시. |

## 코드 읽는 법 (파이썬을 몰라도)

- 흐름: **화면(`static/app.js`) → `/api/...` → `app.py` → `checker.py`가 `nexon.py`로 넥슨을 부름 → 결과를 `db.py`로 저장 → 화면이 그림.**
- 판별 규칙을 바꾸려면 `checker.py`의 `Scanner.run()`(길드원 검색)과 `lookup()`(캐릭터명 검색)을 보면 돼요.
- 파이썬 문법 최소한: `def`는 함수, 들여쓰기가 블록, `#` 뒤는 주석.
