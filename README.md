# 🛡 길드 이중길드 검사기 (guild-checker)

넥슨 API 키 + 서버(월드) + 길드명을 넣고 "검사"를 누르면, **우리 길드원 중 이중길드인 사람**을 찾아 주는 웹이에요. NAS에서 Docker로 띄워 놓고 브라우저로 써요.

- **API 키는 어디에도 저장되지 않아요.** 브라우저에도 서버에도 남기지 않고, 검사하는 동안에만 쓰고 버려요(매번 입력).
- 지난 검사 결과는 저장돼서 다시 보고, **지난번과 비교**(새로 생긴/사라진 이중길드)할 수 있어요.

## 가입 확인 (핸즈 스크린샷 → 닉네임 → 조회)

가입 신청자가 보낸 **메이플 핸즈+ 캐릭터 목록 스크린샷**으로 확인해요. 단계가 나뉘어 있어서 사람이 검수할 수 있어요.

1. **스크린샷 올리기** — 폰은 **[갤러리 열기]**(여러 장 한꺼번에 선택), 컴은 **[사진 고르기]** 또는 **[폴더째 넣기]**(폴더 안 이미지를 이름순으로 전부), 끌어다 놓기·Ctrl+V도 돼요. 최대 10장, 그림을 누르면 크게 보여요.
2. **[닉네임 읽기]** — 모아 둔 스크린샷을 **한 번에** Claude(이미지 인식)에 보내 닉네임을 읽어요. 겹쳐 찍힌 캐릭터는 한 번만 세요.
3. **검수** — 읽은 이름이 텍스트 상자에 한 줄씩 들어와요. 넓은 화면에선 스크린샷이 바로 왼쪽에 있어서 비교하며 고치면 돼요.
   확실하지 않은 이름과, 핸즈 캐릭터 수보다 적게 읽은 경우는 노란 칸으로 알려줘요.
4. **[조회]** — 캐릭터마다 길드·유니온 대표(본캐)·대표의 길드를 보여줘요.
   - **우리 길드 이름**을 넣으면 그 밖의 길드에 있는 캐릭터(또는 대표)를 빨갛게 표시해요.
   - 넣은 캐릭터가 **몇 개 계정**인지 알려줘요. 핸즈 목록이면 1개여야 정상(잘못 읽어서 다른 사람 캐릭터가 됐어도 여기서 드러나요).
   - 없는 이름(오타·개명)은 따로 경고해요. 월드는 캐릭터 정보에서 자동으로 알아내요.
   - **잘못 읽은 이름 바로잡기**: 이미지 인식은 '뇬·쀼' 같은 드문 글자를 '논·뿌'로 읽기 쉬워요. 없는 이름이 나오면 헷갈리는 자모
     (ㅗ/ㅛ, ㅜ/ㅠ, ㅏ/ㅑ, ㅓ/ㅕ, ㄱ/ㄲ, ㅂ/ㅃ, 받침 ㅅ/ㅆ …)를 바꿔 넥슨에서 찾아보고, **같은 계정** 캐릭터면 제안해요. [모두 바꾸고 다시 조회]로 한 번에 고쳐요.
   - 스크린샷은 줄이지 않고(작으면 키워서) Claude가 받을 수 있는 최대 해상도(긴 변 2576px)로 보내요.

Claude 키는 `cp .env.example .env` 해서 `.env`의 `ANTHROPIC_API_KEY=`에 넣거나(그러면 화면 칸이 사라짐), 화면에 매번 넣어요(저장 안 함). 모델은 같은 파일의 `CLAUDE_MODEL=`로 바꿔요.
비용(대략): 스크린샷 4장 한 번에 Opus 5.5 약 100~170원, `.env`에 `CLAUDE_MODEL=claude-haiku-5-5`면 약 5~10원. 결과 화면에 실제 토큰 수가 나와요.

## 판별 원리

유니온 랭킹 API(`/ranking/union`)에 **아무 캐릭터의 ocid**를 넣으면 그 계정의 **유니온 대표 캐릭터** 이름이 나와요. 같은 계정·같은 월드의 캐릭터는 어느 걸로 조회해도 대표가 같아서, 대표 이름으로 묶으면 계정별로 모여요.

1. 길드 이름 → 길드원 명단 (`/guild/id`, `/guild/basic`)
2. 길드원마다 이름 → ocid (`/id`, 캐시)
3. ocid → 유니온 대표 캐릭터 (`/ranking/union`, 며칠 캐시)
4. 대표 캐릭터 → 현재 길드·이미지 (`/character/basic`)
5. 결과
   - **본캐가 다른 길드**(정방향): 대표 캐릭터가 다른 길드에 있음
   - **부캐가 다른 길드**(역방향, 선택): 길드 랭킹 상위 N개 길드의 길드원 대표가 우리 길드원 대표와 같음
   - **실질 길드원**: 대표 기준으로 묶은 인원과 부캐 목록
   - **판별 불가**: 유니온 랭킹에 없는 계정 (조용히 빼지 않고 따로 보여줘요)
   - (선택) **30일 성장 없음**: 어제와 30일 전 레벨·경험치가 같음 (`/ranking/overall`)

날짜는 어제(한국 시간) 기준이에요. 어제 데이터는 오늘 새벽 2시부터 나와서, 2시 전에는 그제 기준으로 봐요.

### 한계
- **대표 캐릭터 ≠ 본캐**일 수 있어요(게임에서 대표를 바꿀 수 있음). 같은 계정 판별은 문제없어요.
- **월드 단위**예요(유니온이 월드별). 다른 월드 부캐는 연결 안 돼요.
- 유니온 랭킹에 없는 계정은 판별 불가예요.
- **하루 전 데이터**예요.
- 역방향은 길드 랭킹 상위 N개만 봐요(그 밖의 작은 길드에 있는 부캐는 못 잡아요).

## 구성

```
브라우저 ──▶ Flask (Docker, 포트 5080) ──▶ 넥슨 Open API
                 │
                 └─ SQLite ./data/guild.db (캐시 · 지난 검사 결과)
```
검사는 백그라운드 작업으로 돌고(동시 8개씩, 429 오류면 쉬었다가 재시도), 화면은 진행률을 받아와서 보여줘요.

## 파일 설명

| 파일 | 역할 |
|---|---|
| `app.py` | Flask 서버. 검사 시작·진행률·결과·지난 검사 목록 API. 받은 API 키는 검사 작업에만 넘기고 저장하지 않아요. |
| `checker.py` | **검사 핵심.** 넥슨 API를 부르는 순서, 대표 캐릭터로 묶기, 정방향·역방향 판별, 중복 호출 방지(메모 + DB 캐시). |
| `nexon.py` | 넥슨 Open API 클라이언트(재시도, 알기 쉬운 오류 메시지). 키는 요청 헤더로만 보내요. |
| `vision.py` | 스크린샷에서 닉네임 읽기(Claude API, 여러 장 한 번에). 읽은 이름은 넥슨 API로 다시 확인해요. |
| `db.py` | SQLite 스키마와 캐시(`ocid_cache` 이름→ocid, `rep_cache` ocid→대표, `char_cache` 캐릭터 정보), 검사 결과 저장. |
| `templates/index.html` | 페이지 뼈대(검사 폼, 결과, 지난 검사). |
| `static/app.js` | 화면 로직: 검사 시작, 진행률 표시, 결과 카드, 지난번과 비교, 라이트/다크 전환. |
| `static/style.css` | 단풍색 라이트 / 다크 테마(그라데이션 없음), 모바일 대응. |
| `tests/mock_nexon.py`, `tests/test_checker.py` | 가짜 넥슨 서버로 검사 흐름 전체를 테스트(`python tests/test_checker.py`, Claude는 가짜로 바꿔서 시험). |
| `Dockerfile`, `docker-compose.yml` | 이미지와 컨테이너(포트 `5080:5000`, `./data` 마운트). `WORKERS`, `REP_TTL_DAYS` 환경변수로 조절 가능. |

## NAS 배포

```bash
cd /volume1/docker && git clone https://github.com/SirohaKR/guild-checker.git && cd guild-checker && mkdir -p data && sudo docker compose up -d --build
```
접속: `http://<NAS-IP>:5080` · 업데이트: `git pull && sudo docker compose up -d --build`

## 코드 읽는 법 (파이썬을 몰라도)

- 흐름: **화면(`static/app.js`) → `/api/scan` → `app.py` → `checker.py`가 `nexon.py`로 넥슨을 부름 → 결과를 `db.py`로 저장 → 화면이 진행률·결과를 받아 그림.**
- 판별 규칙을 바꾸려면 `checker.py` 맨 위 설명과 함수들을 보면 돼요. 숫자 조절(동시 호출 수, 캐시 기간)은 `docker-compose.yml`의 환경변수로 해요.
- 파이썬 문법 최소한: `def`는 함수, 들여쓰기가 블록, `#` 뒤는 주석.
