그 길드의 최신 길드원 목록을 받아서 계정(유니온 대표)별로 묶어 보여줘요. '찾을 계정'을 넣으면 그 사람의 캐릭터가 이 길드에 몇 명 있는지 맨 위에 보여줘요. 의심 결과의 [길드 검색] 버튼을 누르면 자동으로 채워져요.

발급: 넥슨 Open API → 로그인 → 애플리케이션 등록 → 메이플스토리 API 키

Claude API 키 — 스크린샷 닉네임 읽기 (선택)

발급: Claude Console → API Keys. 모델: opus(가장 정확, 스크린샷 4장에 약 150~250원) · sonnet(중간) · haiku(가장 쌈, 드문 글자를 자주 틀림).

설정은 서버의 data/guild.db에 저장돼서 다음에도 그대로 유지돼요. 키는 화면에 앞뒤 몇 글자만 보여줘요. 이 파일엔 키가 들어 있으니 남에게 주지 마세요.
