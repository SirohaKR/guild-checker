넥슨 API 키 — 길드·캐릭터 정보 조회 (필수)

넥슨 API 키 받는 방법 (무료) — 꼭 '서비스 단계'로
  1. openapi.nexon.com 오른쪽 위 로그인 (넥슨 계정)
  2. 내 애플리케이션 → 애플리케이션 등록
  3. 게임은 메이플스토리, 종류는 서비스 단계를 고르고 서비스 이름(예: 우리 길드원 관리), 개발 환경(웹), URL(이 사이트 주소), 설명, 대표 이미지를 넣은 뒤 약관 동의 → 등록
  4. 내 애플리케이션 → 애플리케이션 목록 → 만든 것을 눌러 나오는 API Key(live_로 시작)를 복사해서 위 칸에 붙여넣고 저장

개발 단계 키(test_)는 하루 호출 한도가 너무 적어서 길드원 검색 한 번도 버거워요. 한도는 애플리케이션 화면에서 볼 수 있어요.

Claude API 키 — 스크린샷 닉네임 읽기 (선택)

Claude API 키 받는 방법 (유료, 쓴 만큼)
  1. console.anthropic.com에 가입·로그인
  2. Billing(결제)에서 카드를 등록하고 크레딧을 충전 (예: 5달러면 스크린샷 읽기 수십 번)
  3. API Keys → Create Key → 이름을 넣고 만들기
  4. 나온 키(sk-ant-로 시작)를 바로 복사해서 위 칸에 붙여넣고 저장 — 창을 닫으면 다시 볼 수 없어요

모델: opus(가장 정확, 스크린샷 4장에 약 150~250원) · sonnet(중간) · haiku(가장 쌈, 드문 글자를 자주 틀림). 스크린샷 읽기를 안 쓰면 없어도 돼요.

설정은 서버의 data/guild.db에 저장돼서 다음에도 그대로 유지돼요. 키는 화면에 앞뒤 몇 글자만 보여줘요. 이 파일엔 키가 들어 있으니 남에게 주지 마세요.
